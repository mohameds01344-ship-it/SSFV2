SSF — SUPER STRENGTH FIT
========================
1) افتح index.html مباشرة أو شغّل المشروع باستخدام Live Server في VS Code.
2) المنتجات والأسعار والصور موجودة في script.js داخل مصفوفة PRODUCTS.
3) رقم واتساب الشحن موجود في STORE_CONFIG.whatsappNumber — اكتبه بكود الدولة بدون +.
   مثال مصر: 2010XXXXXXXX
4) أسعار الشحن التجريبية لكل محافظة موجودة في STORE_CONFIG.shipping ويمكن تعديلها.
5) المقاسات والوصف والصور والأسعار قابلة للتعديل لكل منتج.
6) الصور الحالية صور تجريبية من Unsplash. استبدل روابط image بروابط صور منتجاتك أو ملفاتك المحلية.
7) لا توجد قاعدة بيانات أو لوحة تحكم؛ الطلب يُجهز برسالة WhatsApp بعد ملء البيانات.
